Ejercicio 1-IF/ELSE/ENDIF

Crear un programa en PHP que permita determinar si una cadena de texto es larga o corta, utilizando la cantidad de caracteres que tiene. Si tiene más de 5 caracteres, mostrar que es una cadena larga;

de lo contrario, mostrar que es una cadena corta.

Ejercicio 2 DO WHILE

Crear un programa en PHP que utilice un ciclo do while para mostrar los números del 1 al 5, aumentando el número en cada repetición hasta llegar al 5.

Ejercicio 3 VALORES BOOLEANOS

Crear un programa en PHP que utilice una variable de tipo booleano para indicar si una palabra fue encontrada. Si el valor es true, mostrar "La palabra fue encontrada" y si es false, mostrar "La palabra no fue encontrada".
